MÓDULO OFF-GRID — Software de Apoio a Projetos de Instalações Elétricas Agroindustriais (UFPel)

Instalação: copie a pasta "offgrid/" para a raiz do app (ao lado de index.html, css/ e js/)
e substitua o index.html principal (ganha o botão "Módulo off-grid").

Uso com busca automática no CRESESB:
  cd pasta-do-app
  php -S localhost:8000
  abrir http://localhost:8000/offgrid/index.html

Sem PHP (ex.: GitHub Pages): a página funciona igual; a busca automática cai para
"Consulta manual" (copiar a tabela do SunData e colar) ou para a NASA POWER.

sundata.php: o SunData não tem API pública documentada. Se a consulta automática
não reconhecer a tabela, abra o SunData no navegador, faça uma consulta, inspecione
o formulário (F12 > Rede) e ajuste os nomes dos campos no array $campos do sundata.php.

Arquivos: index.html, offgrid.js (cálculos, esquema, PDF, JSON), offgrid.css, sundata.php,
offgrid-exemplo-sitio-leiteiro.json (exemplo; irradiação ilustrativa).
